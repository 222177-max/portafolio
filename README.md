\# Portafolio Personal



Proyecto desarrollado como parte del examen práctico de Git.



\## Descripción

Portafolio web básico que incluye un encabezado de navegación y una sección informativa de inicio.

El proyecto fue desarrollado aplicando buenas prácticas de control de versiones con Git.



\## Tecnologías utilizadas

\- HTML5

\- CSS3

\- JavaScript

\- Git
